# Виртуальный зоопарк

## Описание
Веб-приложение для управления своим зоопарком

## Основные функции

### Клетка для животного
- **Создание клетки для животного**: Пользователь может добавить новую клетку, где будут расположены животные, указав «табличку» и вместимость клетки.
- **Удаление клетки для животного**: Пользователь может удалить клетку для животного (если в клетке уже кто-то проживает, то удаление возможно только после того, как всех животных переселят)
- **Изменение параметров клетки**: Пользователь может изменить клетку (Если в клетке уже кто-то проживает, то новый размер клетки, не должен быть меньше количества проживающих в ней животных)
- **Просмотр клетки с животными**: Пользователь может просмотреть клетку с животными, где будут отображены все проживаемые в ней животные.

Каждая клетка имеет своё название, а также вместимость.

### Животные
- **Добавление животного**: Пользователь может добавить новое животное, указав вид, имя, возраст, описание, а также клетку в которой проживает данное животное (при условии, что место в клетке есть).
- **Просмотр животного**: Пользователь может просмотреть информацию о конкретном животном на отдельной странице.
- **Удаление животного**: Пользователь может удалить животное из зоопарка.
- **Изменение информации о животном**

### Главная страница
На главной странице пользователь должен видеть клетки с животными, при нажатии на которые, можно просмотреть находящихся там зверей.

## Требования к реализации
- Использование Laravel 5 или более поздней версии
- Использование MySQL
- Приложение для развертывания приложения выбирается по желанию (WAMP)
- На каждой странице должны быть ссылки для перехода на другие страницы (навигация)
- Использование миграций для создания таблиц базы данных
- Использование Eloquent ORM для взаимодействия с базой данных (желательно)
- Использование Blade шаблонов для вёрстки страниц

Готовое приложение должно быть полностью рабочим, должны отсутствовать исключения, запросы выполняться корректно, а результат их работы ожидаемым.

## По желанию

## Дополнительные задания
- Создание интерактивного дизайна с помощью JS, Jquery, CSS или Bootstrap
- Добавить возможность пользователям устанавливать изображение для животного, а также просматривать его на странице выбранного животного

### Авторизация пользователей
- Создать окно авторизации
- Окно авторизации не присутствует в навигации (вручную прописывается адрес /login)
- Только авторизованные пользователи могут удалять или добавлять животных, неавторизованные пользователи могут лишь просматривать зоопарк
