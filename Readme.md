## Установка и запуск

### Предварительные требования
- PHP 8.1 или выше
- Composer
- MySQL
- Веб-сервер (Apache/Nginx) или встроенный сервер PHP

### Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repository-url>
   cd virtual-zoo
   ```

2. **Установите зависимости:**
   ```bash
   composer install
   ```

3. **Настройте окружение:**
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

4. **Настройте базу данных в файле `.env`:**
   ```env
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=virtual_zoo
   DB_USERNAME=root
   DB_PASSWORD=
   ```

5. **Создайте базу данных:**
   ```sql
   CREATE DATABASE virtual_zoo;
   ```

6. **Запустите миграции:**
   ```bash
   php artisan migrate
   ```

7. **Создайте символическую ссылку для хранения файлов:**
   ```bash
   php artisan storage:link
   ```

8. **Запустите приложение:**
   ```bash
   php artisan serve
   ```

   Приложение будет доступно по адресу: http://localhost:8000

## Использование

### Главная страница
- Отображает все клетки зоопарка
- Показывает статистику: количество клеток, животных, общую вместимость
- Позволяет перейти к детальному просмотру клеток

### Управление клетками
- **Создание:** Укажите название, вместимость и описание
- **Просмотр:** Информация о клетке и список животных
- **Редактирование:** Изменение параметров (с учетом проживающих животных)
- **Удаление:** Только для пустых клеток

### Управление животными
- **Добавление:** Вид, имя, возраст, клетка, описание, фото
- **Просмотр:** Полная информация о животном
- **Редактирование:** Изменение всех параметров
- **Удаление:** Удаление животного из зоопарка

Контроллеры
CageController
index() — список клеток с животными
show() — детали клетки
create() — форма создания (только авторизованные)
store() — сохранение (только авторизованные)
edit() — форма редактирования (только авторизованные)
update() — обновление (только авторизованные)
destroy() — удаление (только авторизованные)
AnimalController
index() — список животных
show() — детали животного
create() — форма создания (только авторизованные)
store() — сохранение с загрузкой изображения (только авторизованные)
edit() — форма редактирования (только авторизованные)
update() — обновление с заменой изображения (только авторизованные)
destroy() — удаление с удалением изображения (только авторизованные)

## AuthController

login() — обработка входа
showRegisterForm() — форма регистрации
register() — обработка регистрации
logout() — выход
